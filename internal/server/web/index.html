Tools

Lower-level operations. All of them read the source read-only.

Source

Mount read-only

Asks the system to mount the volume without writing to it. On macOS, disk images are attached read-only and hidden from Finder.

Check filesystem (read-only)

Runs the system's own checker in no-write mode (fsck -n on macOS/Linux, chkdsk without /f on Windows) to show what is damaged. It never repairs or changes anything.

Find lost partitions

Searches the whole source for boot sectors and superblocks, including backup copies.

Byte-to-byte image

Copies every sector to an image, zero-filling unreadable ones. Use it for failing drives, then scan the image.

Repair a copy

Restores a wiped boot sector from its backup inside a new image, then you can attach that image.
