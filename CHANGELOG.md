# Changelog

## 0.1.0: first release
- Single-file app for macOS (universal), Windows (x64, ARM64) and Linux (x64, ARM64)
- HFS+/HFSX quick scan with deleted entries from stale catalog nodes and the journal; works on volumes with a
  damaged catalog header
- Deep scan by file signature (PNG, JPEG, GIF, BMP, PDF, ZIP/Office, SQLite, MP4/MOV, WAV/AVI/WebP), free space only
- Saved scans, file browser with resizable columns, preview, selective recovery to another drive
- Tools: diagnose, lost partitions, byte-to-byte image, boot-sector repair on a copy, read-only filesystem check,
  read-only mount
